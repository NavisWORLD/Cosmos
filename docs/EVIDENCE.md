# Evidence and Claim Discipline

COSMOS uses six labels:

- **IMPLEMENTED** — source/artifact exists.
- **OBSERVED** — captured runtime evidence shows execution.
- **MEASURED** — a defined benchmark produced a metric.
- **NULL** — the declared test did not support the proposed advantage.
- **HYPOTHESIS** — falsifiable proposition awaiting/under testing.
- **METAPHOR_MODEL** — conceptual language, not literal physics/biology.

## Mandatory distinction

A system can be persistent, autonomous, sensory, self-monitoring, or able to describe itself without that establishing consciousness.

A quantum measurement/seed can provide auditable provenance without improving an ML objective. Performance advantage requires matched controls.

## State-mechanism preflight

Before accepting an architecture benchmark, verify state variation, useful kernel geometry, non-degenerate mixing/gates in the relevant implementation, fixed datasets, stable telemetry schema, and reproducible seeds/configuration.
