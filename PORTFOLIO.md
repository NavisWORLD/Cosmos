# COSMOS / Reality Bridge Research & Engineering Portfolio

**Creator / research lead: Cory Shane Davis / NavisWORLD**

This repository contains the structured engineering portfolio for **COSMOS**, **Davis Cosmic Synapse Theory (CST)**, PHOS, Reality Bridge, simulation, creative-computing, and related research-engineering work.

The project’s canonical narrative is documented in [`ORIGIN_AND_PROVENANCE.md`](ORIGIN_AND_PROVENANCE.md). The short lineage is **2018 → 2024 → 2026**: personal/conceptual origin → formal CST research → integrated source-first COSMOS runtime.

**Start here:** [PORTFOLIO/README.md](PORTFOLIO/README.md)

The portfolio is designed to answer five questions for an engineer, researcher, recruiter, collaborator, or reviewer:

1. What did Cory actually build or document?
2. What code or artifact corresponds to it?
3. What has actually been measured or observed?
4. What remains a hypothesis, prototype, creative experiment, or publication gap?
5. Which material is Cory-owned original work and which material is third-party, prior art, or governed by another license?

The portfolio deliberately uses evidence labels so implementation is not confused with validation and metaphor is not confused with physics or biology.
