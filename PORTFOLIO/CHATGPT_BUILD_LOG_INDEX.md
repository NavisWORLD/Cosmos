## How a chat enters the canonical archive
1. Preserve the exact share URL.
2. Record the conversation title and date.
3. Summarize the problem, key decisions, output artifacts, corrections, and unresolved questions.
4. Link the conversation to the corresponding manual.
5. Link the manual to the source code / benchmark / artifact.
6. Never use the conversation itself as proof of an empirical claim.
