## Publication workflow
1. Locate canonical artifact.
2. Strip secrets/private data.
3. Verify third-party licensing.
4. Run basic execution/syntax check.
5. Add README with inputs, outputs, limitations, status.
6. Commit artifact.
7. Replace publication-pending entry with direct source link.
8. Preserve original artifact hash when practical.
