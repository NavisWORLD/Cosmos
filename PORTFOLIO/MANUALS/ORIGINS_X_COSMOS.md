# Origins × COSMOS / Prajna Integration Manual

## Purpose
Understand a third-party public project on its own terms, then connect reusable COSMOS pieces without falsely claiming authorship, affiliation, endorsement, or validation.

## Method
1. Read upstream objects/data flow/dependencies/licenses/claims first.
2. Build translation table: original concept, I/O, possible COSMOS interface, literal vs approximate mapping.
3. Keep namespaces distinct (`origins.*`, `cosmos.*`).
4. Define baseline/metric/null before claiming improvement.
5. Treat quantum-derived input only as explicit provenance/seed/control/experimental feature with provider labels.

## Prototype architecture
`upstream state/data → adapter/schema → optional COSMOS state/memory/evidence → experiment/visualization → metrics/provenance`

## Attribution
State what belongs upstream, what adapter/experiment was added here, what was measured here, and what remains speculative.
